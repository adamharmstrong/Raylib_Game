# First-Party Audio

`power_pulley_panic_wendi_01_three_step_tumble.wav` is the original 24-bar,
132 BPM E-minor theme for Wendi's Three-Step Tumble. Its three-note metallic
motif represents the level's three-button cascade, while rolling fills, chain
ticks, synthesized drums, bass, and pads support the playful industrial setting.
The seamless 43.6-second loop is rendered entirely from original synthesized
material by `tools/build_wendis_level_01_theme.py`.
